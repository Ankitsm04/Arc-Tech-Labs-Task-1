# Arc-Tech Labs Task 1

## Project Description
This project is a React.js application that integrates Material-UI (MUI) for building responsive UI components. It demonstrates the use of async/await for fetching data from an API, displaying the results in a Material-UI table, and managing state with Redux.

## Features
- Fetch data from the [JSON Placeholder API](https://jsonplaceholder.typicode.com/).
- Display the fetched data in a Material-UI table.
- Implement responsive design for mobile and laptop screens.
- Use Redux for state management.

## Prerequisites
- Node.js (v16 or higher)
- npm (Node Package Manager)
